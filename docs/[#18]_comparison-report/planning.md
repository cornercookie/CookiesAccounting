## 功能描述

在既有 yearly_report.php 與 quarterly_report.php 基礎上，加入「本月 vs 上月」與「今年 vs 去年」同一類別的並列對比報表，讓家庭了解各類別支出的趨勢變化。

## 專案函數與術語說明

- 輸出轉義函式（h()）：用於防護跨站腳本（XSS），所有使用者可控輸出皆經此函式。
- 登入保護機制（requireLogin()）：檢查 $_SESSION['user_id']，未登入導向登入頁。
- 帳本存取權限表（ledger_access）：記錄使用者對各帳本的角色（擁有者/member/檢視者）。
- PHP 資料物件（PDO）：用於資料庫查詢的預備陳述式介面，選用理由為符合專案「純 PHP + PDO 預備陳述式」技術約束，防止 SQL 注入。
- 可縮放向量圖形（SVG）：用於圖表繪製，選用理由為無需 Node.js 前端庫，純伺服端渲染即可產生條形圖，符合「無框架、無 Node.js」技術約束。
- 跨站請求偽造（CSRF）：防護網頁請求被偽造的機制，選用理由為專案技術約束明確要求所有狀態變更表單皆有 CSRF 防護。
- 預寫式日誌（WAL）：SQLite 資料庫日誌模式，支援多讀寫併發，選用理由為 SQLite 在多併發讀寫場景下可避免鎖定失敗，符合 cPanel 主機環境需求。
- 分類支出明細表（entries）：儲存所有記帳分類支出記錄的資料表，包含類別、金額、日期等欄位。

## 使用者故事

作為家庭成員，我想比較本月與上月、今年與去年的各類別支出，了解哪些類別花費增加或減少。

## 預期行為

1. 報表頁面顯示兩個時間區間並列（例如 本月 vs 上月、今年 vs 去年）。
2. 每個類別顯示兩區間的金額與差額（絕對值與百分比）。
3. 支援類別篩選與帳本篩選（僅顯示使用者有存取權的帳本）。
4. 金額以整數分儲存，顯示時除以 100，千分位格式。
5. 使用 可縮放向量圖形（SVG）條形圖並列顯示兩區間對比（復用 ledger.php 類別統計 SVG 模式）。
6. 所有輸出經 超文字標記語言（HTML）輸出轉義函式（h()）轉義。
7. SQL 查詢使用 PHP 資料物件（PDO）預備陳述式，具名佔位符。
8. 日期區間以 記帳日期（entry_date）BETWEEN 查詢，軟刪除標記欄位（deleted）= 0（0 表示未刪除記錄）。
9. 無資料時顯示「尚無記錄」。
10. 篩選表單若提交，須驗證 跨站請求偽造（CSRF）權杖，權杖驗證失敗則拒絕請求並顯示錯誤訊息。

## 資料流（Data Flow）

使用者於報表頁面選擇比較模式（本月 vs 上月 或 今年 vs 去年）與帳本；伺服端驗證登入階段與 帳本存取權限表（ledger_access）權限；以 PHP 資料物件（PDO）預備陳述式分別查詢兩個日期區間的 entries 表，以 category 分組加總 amount_cents；計算差額與百分比；以 可縮放向量圖形（SVG）條形圖並列呈現；所有輸出經 超文字標記語言（HTML）輸出轉義函式（h()）轉義。日期格式錯誤時回傳 400，資料庫查詢失敗時顯示通用錯誤頁並記錄至 error.log，無資料時顯示「尚無記錄」。

## 業務驗收條件

- 比較報表頁面（comparison_report.php）可供使用者存取。
- 未登入使用者導向登入頁。
- 權限檢查：僅顯示使用者有帳本存取權限（ledger_access）的帳本資料。
- 支援兩種比較模式：本月 vs 上月、今年 vs 去年。
- 各類別金額差額以整數直接相減比較，百分比採整數運算計算，禁止使用浮點數資料類型（FLOAT）。
- 可縮放向量圖形（SVG）條形圖兩區間並列，圖例與標籤使用中文。
- 所有輸出經 超文字標記語言（HTML）輸出轉義函式（h()）轉義。
- 篩選表單若提交，須驗證 跨站請求偽造（CSRF）權杖，權杖驗證失敗則拒絕請求並顯示錯誤訊息。

## 錯誤處理與邊界條件

- 日期區間格式錯誤：顯示錯誤訊息，不執行查詢，HTTP 回應 400。
- 資料庫查詢失敗：顯示通用錯誤頁，詳細錯誤寫入 private_data/error.log。
- 權限不足：requireLogin 未通過導向登入頁；ledger_access 無對應帳本則不顯示該帳本資料。
- 無資料：顯示「尚無記錄」，非錯誤狀態。

## 身分驗證與權限控管

- 身分驗證：依賴既有 session 登入機制，requireLogin() 檢查 $_SESSION['user_id']，未登入導向 login.php。
- 權限控管：使用帳本存取權限表 ledger_access，角色分為擁有者（owner）、成員（member）、檢視者（viewer），僅顯示使用者有存取權限的帳本資料。
- 資料傳輸加密：依賴既有 超文字傳輸協定安全版（HTTPS）Session Cookie 設定（secure 僅安全連線傳送、HttpOnly 僅伺服端可存取、SameSite=Lax 跨站請求限制）。

## 非本期範圍（Out of Scope）

- 多年趨勢圖：本期僅支援兩區間對比，不支援多年趨勢圖表。
- 匯出比較報表 PDF：本期僅於網頁顯示，不匯出 PDF。
- 預警通知：本期不自動發送預算超支或趨勢異常通知。

## 非功能性需求

- 預期效能：報表頁面載入時間不超過 3 秒（兩區間查詢）。
- 併發處理量：唯讀查詢，SQLite WAL 模式支援多併發讀取。
- 資料保留策略：報表不產生額外資料，不涉及資料保留。
- 系統可用性：單一區間查詢失敗時可顯示另一區間結果，避免整頁失效。
