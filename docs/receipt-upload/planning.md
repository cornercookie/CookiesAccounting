# Planning: 拍照收據 / 發票小圖夾

## Description

讓使用者在記帳（新增或編輯記錄）時，可以隨手拍照或上傳收據、發票照片，系統將其安全儲存於後端私密資料夾中，並透過權限驗證與亂數命名機制作為防護，在明細與詳情頁面提供小圖夾檢視與點擊放大功能，方便核對家庭開銷。

## User Story

- 作為家庭成員，我希望買大件物品或聚餐時可以順便拍下發票收據上傳，這樣報帳或核對時才不會找不到紙本。
- 作為管理者/檢視者，我希望能在帳本明細中隨時點開小圖看當時的收據照片，且確保隱私不外洩。

## To Reproduce

1. 進入新增記錄頁面。
2. 點擊「上傳收據/發票照片」選擇檔案或使用手機相機拍照。
3. 提交記錄後，後端進行嚴格的副檔名與 MIME Type 檢查，並使用亂數命名儲存於 `private_data/uploads/` 目錄。
4. 在帳本明細列表中點擊收據圖示，經由後端權限檢查後串流輸出圖片供檢視。

## Expected behavior

- **安全防護 (SEC-02)**：
  1. 禁止直接透過網址靜態存取 `private_data/uploads/`（透過 `.htaccess` 或將檔案置於 Web Root 外）。
  2. 檔案強制重新命名（使用 `bin2hex(random_bytes(16))` + 副檔名對應），防止 WebShell 執行與檔名碰撞。
  3. 嚴格檢查上傳檔案的 MIME Type 與大小（上限 5MB，僅允許 JPEG, PNG, WebP）。
- 刪除或作廢記錄時處理關聯檔案。

## Acceptance Criteria

1. 新增記錄表單包含選填的圖片上傳欄位。
2. 上傳的檔案經後端安全檢查、亂數重新命名並儲存於私密目錄。
3. 帳本明細與詳情頁面透過安全路由正確顯示收據縮圖，點擊可放大檢視，且未授權者無法存取。
4. 具備完整的檔案大小與格式錯誤提示。

## Additional context

- 需確保 `private_data/uploads/` 目錄具備寫入權限，並配合 `.htaccess` 拒絕直接存取。
