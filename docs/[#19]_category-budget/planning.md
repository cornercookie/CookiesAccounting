## 功能描述

擴充既有帳本層級每月預算，新增類別層級預算（例如「餐費月預算 6000 元」），超過時在 ledger.php 與 dashboard.php 顯示警告。僅帳本擁有者可設定類別預算。

## 專案函數與術語說明

- 輸出轉義函數（h()）：輸出轉義，用於防護跨站腳本（XSS）。
- 跨站請求偽造（CSRF）：防護網頁請求被偽造的機制。
- 恆時比對函數（hash_equals()）：用於常數時間比對 CSRF 權杖，防止時序攻擊。
- PHP 資料物件（PDO）：用於資料庫查詢的預備陳述式介面，選用理由為符合專案「純 PHP + PDO 預備陳述式」技術約束，防止 SQL 注入。
- 預寫日誌（WAL）：SQLite 資料庫日誌模式，支援多讀寫併發，選用理由為 SQLite 在多併發讀寫場景下可避免鎖定失敗，符合共享主機環境需求。
- 帳本存取權限表（ledger_access）：記錄使用者對各帳本的角色（擁有者（owner）/成員（member）/檢視者（viewer））。
- 登入保護機制（requireLogin()）：檢查 $_SESSION['user_id']，未登入導向登入頁。
- 金額分轉元格式化函數（formatCents()）：將整數分儲存的金額轉換為元並保留兩位小數。
- 稽查記錄表（audit_log）：記錄誰在何時做了什麼操作，僅新增不刪除。
- 類別預算表（category_budgets）：儲存各帳本類別層級每月預算的資料表，欄位包括：
  - 帳本 ID（ledger_id）：關聯至帳本表的識別碼。
  - 類別名稱（category）：業務意義為該預算適用的支出類別名稱。
  - 每月預算金額（monthly_budget_cents）：以整數分儲存，業務意義為該類別每月允許的最高支出金額。
  - 是否啟用（is_active）：業務意義為該類別預算是否生效，1 表示啟用，0 表示停用。
  - 建立時間（created_at）：業務意義為該預算記錄的建立日期時間。
  - 更新時間（updated_at）：業務意義為該預算記錄最後一次變更的日期時間。

## 使用者故事

作為帳本擁有者，我想為特定類別（如餐費、娛樂）設定每月預算，超過時收到警告，避免單一類別支出失控。

## 預期行為

1. 新增資料表 category_budgets（ledger_id, category, monthly_budget_cents, is_active, created_at, updated_at）。
2. ledger.php 月份檢視時，查詢各類別本月支出並與類別預算比較。
3. 類別支出 ≥ 80% 預算顯示警告，≥ 100% 顯示危險（與既有帳本預算邏輯一致）。
4. 新增類別預算設定頁面，僅擁有者可新增/編輯/刪除。
5. 跨站請求偽造（CSRF）權杖防護，所有寫入表單含 csrf_token，以 hash_equals() 驗證。
6. 金額以整數分儲存，顯示除以 100。
7. 所有輸出經 h() 轉義。
8. SQL 查詢使用 PDO 預備陳述式，具名佔位符。
9. 權限檢查：僅帳本存取權限表（ledger_access）role = 'owner' 可修改類別預算。
10. 類別預算與帳本整體預算並存，不互相衝突。

## 資料流（Data Flow）

擁有者於類別預算設定頁面輸入類別名稱與每月預算金額；表單含 CSRF 權杖，以 hash_equals() 驗證；以 PDO 預備陳述式 INSERT 或 UPDATE category_budgets 表；ledger.php 月份檢視時，以 PDO 預備陳述式查詢 entries 表各類別本月支出（SUM(amount_cents) WHERE type='expense' GROUP BY category），與 category_budgets 左連結比較支出 vs 預算；支出 ≥ 80% 預算顯示警告，≥ 100% 顯示危險；所有輸出經 h() 轉義。

```mermaid
flowchart TD
    A[擁有者輸入類別與預算金額] --> B[CSRF 權杖 hash_equals 驗證]
    B --> C[PDO INSERT/UPDATE category_budgets]
    C --> D[ledger.php 查詢entries各類別支出]
    D --> E[與 category_budgets 左連結比較]
    E --> F[≥80% 警告 ≥100% 危險 h() 轉義顯示]
```

## 業務驗收條件

- 類別預算設定頁面可供帳本擁有者存取，僅擁有者可新增、編輯、刪除類別預算。
- 類別預算表單提交時，系統驗證跨站請求偽造（CSRF）權杖，驗證失敗拒絕請求。
- ledger.php 月份檢視頁面顯示各類別本月支出與類別預算的比較結果。
- 類別支出達預算 80% 時顯示警告，達 100% 時顯示危險。
- dashboard.php 頁面顯示類別預算警告橫幅。
- 所有使用者可控輸出經輸出轉義函數（h()）轉義，防護跨站腳本（XSS）。

## 錯誤處理與邊界條件

- CSRF 權杖驗證失敗：拒絕請求，顯示通用錯誤訊息。
- 資料庫寫入失敗：顯示通用錯誤頁，詳細錯誤寫入 private_data/error.log。
- 無預算設定時：不顯示類別預警區塊，維持原版面。
- 金額負值或零值：顯示錯誤訊息，不寫入資料庫。
- 同時編輯衝突：最後寫入者勝出，無鎖定機制，audit_log 記錄變更。

## 身分驗證與權限控管

- 身分驗證：依賴既有 session 登入機制，requireLogin() 檢查 $_SESSION['user_id']，未登入導向 login.php。
- 權限控管：使用帳本存取權限表 ledger_access，僅 role = 'owner' 可新增/編輯/刪除類別預算；member 與 viewer 僅可檢視。
- 資料傳輸加密：依賴既有 HTTPS Session Cookie 設定（secure、HttpOnly、SameSite=Lax）。

## 非本期範圍（Out of Scope）

- 類別預算通知：本期僅於網頁顯示警告，不發送電子郵件或推播通知。
- 年度類別預算：本期僅支援每月預算，不支援年度預算。
- 預算轉撥：本期不支援類別間預算轉撥。

## 非功能性需求

- 預期效能：類別預算查詢與既有月份彙總合併執行，不顯著增加頁面載入時間。
- 併發處理量：類別預算寫入為單筆操作，SQLite WAL 模式支援多併發。
- 資料保留策略：category_budgets 記錄長期保留，與帳本生命週期一致。
- 系統可用性：類別預算頁面失敗不影響主帳本檢視功能。
