## 功能描述

本期多幣別功能（[#24]）實作範圍為**單筆記錄**的新增、編輯、顯示、導出。重複記錄功能本身**不支援多幣別**，僅支援台幣（TWD）金額。重複記錄產生分錄時，自動以 TWD、匯率 1.0000、原幣金額等於台幣金額寫入。

此文件明確記錄此限制，避免未來誤以為重複記錄應支援多幣別而產生規格爭議。

## 預期行為

1. **重複記錄建立/編輯表單**：僅有金額欄位（台幣），無幣別下拉、匯率輸入、原幣金額欄位
2. **重複記錄產生分錄**：
   - `currency = 'TWD'`
   - `exchange_rate = 10000` (basis points，即 1.0000)
   - `original_amount_cents = amount_cents`（台幣金額即原幣金額）
3. **列表顯示**：重複記錄列表僅顯示台幣金額，不顯示幣別/匯率/原幣金額
4. **產生分錄後**：該分錄在 `ledger.php` 列表中正確顯示為 TWD（幣別標籤、原幣金額=台幣金額、匯率=1.0000）

## 設計決策理由

1. **範疇控制**：本期 [#24] 專注於單筆記錄多幣別，重複記錄涉及排程、通知、編輯同步等複雜度，納入將顯著延期
2. **使用場景**：重複記錄多為固定台幣支出（房租、水電、訂閱費），外幣重複記錄需求極低
3. **技術債務控制**：`recurring_entries` 表結構變更涉及遷移、排程器修改、編輯同步邏輯，風險較高
3. **未來擴充性**：`recurring_entries` 表未來可加 `currency`、`exchange_rate`、`original_amount_cents` 欄位，`generate_recurring` 邏輯已預留擴充點（產生分錄時已正確填入三欄位）
