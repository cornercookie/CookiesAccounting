# Planning: 一鍵匯出 Excel (CSV)

## Description

提供帳本成員將帳本內的收支明細一鍵匯出為標準 CSV 檔案（可用 Excel 直接開啟），並內建 CSV 公式注入防護與嚴格的帳本存取權限驗證，方便家庭成員自行備份。

## User Story

- 作為家庭成員，我希望能把今年所有的收支明細下載成 Excel 檔案，以便自己做年度報表歸檔。

## To Reproduce

1. 進入指定的帳本詳情頁面。
2. 點擊「匯出明細 CSV」按鈕（系統檢查當前使用者是否具備該帳本的存取權限）。
3. 瀏覽器下載安全過濾後的 CSV 檔案。
4. 使用 Microsoft Excel 開啟，確認中文與金額正常顯示，且無公式注入風險。

## Expected behavior

- **安全防護 (SEC-03, SEC-04)**：
  1. **IDOR 權限檢查**：匯出前必須檢查使用者對該帳本是否擁有讀取權限。
  2. **CSV 公式注入防護**：對所有輸出的文字欄位（如備註、分類），若內容開頭為 `=`, `+`, `-`, `@` 等危險字元，強制在其前方加上單引號 `'` 或使用雙引號完整包覆，防止 Excel 執行惡意巨集或指令。
- 輸出符合 UTF-8 with BOM 編碼的 CSV 檔案，確保 Excel 開啟中文不會亂碼。
- 包含欄位：日期、類型、金額（元）、分類、記錄者、備註。

## Acceptance Criteria

1. 帳本頁面提供「匯出 CSV」操作按鈕。
2. 匯出動作具備嚴格的帳本權限驗證。
3. 輸出欄位經過防公式注入處理，且金額正確轉換為元。
4. 中文編碼在 Excel 中正常顯示（UTF-8 BOM）。

## Additional context

- 純 PHP 實作，無需額外套件。
