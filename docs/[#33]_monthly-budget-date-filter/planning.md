# [#33] 單日篩選不應改變本月預算

> 本文件為規劃文件，不完全是實作依據。

## Description

續驗 [#5]：帳本切到單日篩選後，顯示的「本月預算」從當月支出退化為單日支出。

## User Story

查閱單日分錄時，仍能看見這本帳本真正的本月預算使用情況。

## To Reproduce

於隔離 PHP／SQLite 設 100.00 元預算，在當月兩天分別記 2.00 元與 88.00 元支出。整月頁與儀表板顯示 90% 警示；同月篩到只有 2.00 元支出的第一天，舊頁的月預算變成 2%，警示消失。

## Expected behavior

月預算始終用所選當月的整月有效支出，不受單日篩選影響；單日分錄與當日小計仍依既有篩選。

## Acceptance Criteria

- [ ] 同月底下切到單日仍顯示 90% 警示、月支出 90.00 元及剩餘 10.00 元，當日支出小計仍是 2.00 元。
- [ ] 不計收入、轉帳、作廢或其他月份。歷史月份仍不顯示本月預算。

## Additional context

只修帳本詳情計算月份範圍；不改 [#32] 提示版型、會話、權限、預算設定或部署。
