## 二、複審發現的新議題

### N-01（Minor）：Design.md 第 66 行 SVG 屬性說明與實作不符
- **文件說明**：`SVG <rect> 的 x/y/width/height/fill 為 PHP 計算之數字，強制 cast 為數值`
- **實際實作**：`fill` 已移除（由 CSS 變數處理），不再是 PHP 計算的數值
- **建議**：更新說明為「SVG `<rect>` 的 x/y/width/height 為 PHP 計算之數字，強制 cast 為數值；fill 由 CSS 變數 `var(--blue)` 控制」

### N-02（Minor）：回退表格佔比計算重複邏輯
- **位置**：ledger.php 第 808 行
- **程式碼**：`(int) (($stat['cents'] / $categoryTotalCents) * 100)`
- **問題**：與第 775 行 SVG 區塊的百分比計算重複，建議提取為變數或函數
- **風險**：低（僅顯示用，不影響資料正確性）

### N-03（Info）：logAudit 動作代碼命名
- **位置**：ledger.php 第 789 行
- **代碼**：`'category_svg_fallback'`
- **建議**：依專案慣例建議改為 `category_chart_fallback` 或 `svg_generation_fallback`，但非阻塞項
