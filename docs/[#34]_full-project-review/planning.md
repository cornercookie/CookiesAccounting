# [#34] 全專案審查

> 本文件為規劃文件，不完全是實作依據。

## Description

開發者要求：「全專案審查；懷疑先前提交未真正修復問題或讓功能可用；目標是程式可用並達成優化。」本次須核實並修正權限、CSV 匯入、比較報表、類別預算、效能、登出與提示、稽核及每月重複記錄，以回歸驗證確認功能可用。

## User Story

身為開發者，我希望全專案審查能找出先前提交仍未修復或不可用的問題並完成修正，以便系統功能可用且效能獲得優化。

## To Reproduce

修正前可依序觀察：未登入開啟 `fix_db.php` 可讀取原始碼並改寫 `db.php`；member 可修改／作廢他人記錄，viewer 可從重複記錄新增記錄；系統匯出的 9 欄 CSV 無法匯入，`logError` 參數數量錯誤會造成 HTTP 500；比較報表在本期 306.00、上期 200.00 時將總差額顯示為 494；類別預算不能自由輸入類別；結構升級重複執行且儀表板提醒採 N+1 查詢；GET `logout.php` 即登出，`?msg=` 可放入偽造釣魚文字；封存／還原帳本未寫稽核；「立即記一筆」不推進下次日期且同月可無限重複。

## Expected behavior

修正後須關閉未授權寫入與偽造途徑，讓合法使用者能完成 CSV 往返、報表、預算及每月重複記錄操作，並以結構版本、索引與單一查詢降低重複工作；各項完成條件如下。

## Acceptance Criteria

- [ ] 移除 `fix_db.php`、`temp_check.txt`、`nul` 與未被引用的 `lib/tcpdf`，不再暴露未登入讀取原始碼或改寫 `db.php` 的入口。
- [ ] member 只能修改／作廢自己建立的記錄，owner 可修改／作廢帳本內記錄而不受建立者限制；viewer 不能透過 `generate_recurring` 新增記錄。
- [ ] `import_csv.php` 可匯入系統匯出的 9 欄 CSV，不再因 `logError` 參數數量錯誤回 HTTP 500；比較報表本期 306.00、上期 200.00 的總差額顯示 `+106.00`，不再是 494。
- [ ] 類別預算可自由輸入類別，帳本頁顯示轉帳合計與行事曆連結；同一結構版本只升級一次，新增兩個複合索引，儀表板重複記錄提醒由 N+1 改為單一 GROUP BY 查詢。
- [ ] GET 登出頁只顯示確認，POST 且通過 CSRF 才登出；`?msg=` 須有有效簽章才顯示；封存／還原帳本分別寫入 `ledger_archive`／`ledger_restore` 稽核。
- [ ] 「立即記一筆」產生後依起始日之日數按月推進，月底夾到該月最後一天（1/31 → 2/28 → 3/31）；在 `BEGIN IMMEDIATE` 交易內排除本月已有未作廢記錄的重複產生，已作廢者不計，重複時提示「本月已產生過此重複記錄。」。

## Additional context

- **非本期範圍**：不支援每月以外的重複頻率；[#1] 規格本即僅支援每月。
- **其他未結項目**：無。
