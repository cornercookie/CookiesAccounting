# Planning: 預算紅線與超支提醒

## Description

允許帳本擁有者或管理員為帳本設定「每月總預算」，系統在儀表板與帳本詳情頁計算本月累積支出，當接近或超過預算時顯示醒目的超支提醒標籤，並落實嚴格的權限控管，協助家庭成員控制開銷。

## User Story

- 作為家長/帳本擁有者，我希望能為家庭帳本設定每月預算上限，讓大家隨時知道花費進度。
- 作為家庭成員，我希望能一眼看出本月預算還剩多少，避免不小心花過頭。

## To Reproduce

1. 進入帳本設定頁面（需檢查使用者是否為該帳本之 owner / admin）。
2. 輸入每月總預算金額並儲存。
3. 系統自動統計當月該帳本的所有支出記錄總額。
4. 在帳本儀表板顯示預算進度條與百分比，達到 80% 顯示警告，超過 100% 顯示超支提醒。

## Expected behavior

- **安全控管 (SEC-04)**：設定與修改預算前，必須驗證當前登入者是否具備該帳本的管理權限（Owner 或 Admin），防止 IDOR 越權修改。
- 帳本資料表新增 `monthly_budget` 欄位（以分為單位整數儲存）。
- 自動計算當月 1 日至當月底的支出總和。

## Acceptance Criteria

1. 帳本管理/設定頁面可設定及修改每月預算（具備權限檢查）。
2. 帳本詳情頁面正確顯示本月預算、已花費金額與剩餘額度。
3. 當花費比例超過 80% 及 100% 時，呈現對應的警示標籤（Warning / Danger）。
4. 無設定預算時維持原有乾淨版面。

## Additional context

- 需配合現有 SQLite 資料庫結構進行輕量 migration。
