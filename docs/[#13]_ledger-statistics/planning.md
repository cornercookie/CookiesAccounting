# Planning: 查帳統計與提醒（成員記帳進度、預算超支提醒、列印月結單、類別統計圖表）

## Description

在儀表板與帳本詳情頁加入四項查帳與統計功能，讓家庭成員一目了然地掌握家庭收支：

1. **成員記帳進度（Feature 6）**：儀表板新增區塊，顯示各成員本月已記錄的筆數，讓管理員或家長一眼知道誰還沒記帳，避免月底對帳時發現缺記錄。
2. **預算超支醒目提醒（Feature 7）**：現有每月預算功能已在帳本詳情頁顯示進度條，本項加強在儀表板與帳本詳情頁顯示更醒目的超支提醒橫幅（本月支出達預算 80% 顯示警告、達 100% 顯示超支）。
3. **列印友善月結單（Feature 9）**：帳本詳情頁加入列印樣式（@media print），隱藏側欄、導覽與操作按鈕，只保留三聯合計牌與本月分錄表，適合家中列印貼於冰箱上供長輩核對。
4. **類別統計圖表（Feature 10）**：帳本詳情頁加入 SVG 長條圖，顯示本月各類別支出佔比，全在 PHP 端產生，不需前端圖表庫。

範圍限於前述四項，不擴充至多年度比較、多帳本彙總或圖表匯出等功能。

## User Story

- 作為家長，我希望在儀表板看到各家人本月記帳筆數，知道誰還沒記，避免月底對帳時記錄不全。
- 作為家庭成員，我希望本月支出接近預算時看到醒目提醒，控制開銷。
- 作為長輩，我希望能列印乾淨的本月結單，貼在家中方便核對。
- 作為家庭成員，我希望看到本月各類別支出佔比圖表，知道錢花在哪裡。

## To Reproduce

本項目非錯誤（bug）類需求，不適用重現步驟。

## Expected behavior

- **成員記帳進度**：儀表板顯示「本月各成員記帳進度」列表，針對每個可存取帳本分別查詢，列出該帳本內每位成員的 username 與本月已記錄筆數（不含作廢記錄，deleted = 0）；成員若未登入或本月無記錄，顯示 0 筆；管理員與一般成員皆可檢視。SQL 必須加入 `WHERE e.ledger_id = :ledger_id` 與 `AND e.deleted = 0`，並與 `ledger_access` join，僅統計該帳本本月未刪除記錄，避免跨帳本洩漏成員活動。
- **預算超支醒目提醒**：預算超支橫幅僅在「當月（Asia/Taipei）」顯示。當帳本已設定每月預算（monthly_budget_cents > 0）且查看月份為當月（$ym === 本月）且本月支出 ≥80% 預算時，儀表板與帳本詳情頁頂部顯示黃色警告橫幅；支出 ≥100% 時顯示紅色超支橫幅；未設定預算或查看歷史月份則不顯示任何預算區塊，維持現有版面。
- **列印友善月結單**：帳本詳情頁在 `<head>` 內嵌 `@media print` 樣式，隱藏 `.side`（側欄）、`.nav`（導覽列）、`.ctr-actions`（操作欄）與 `.quick`（快速入口），只保留頁面標題、三聯合計牌（`.plates`、收入／支出／結餘）與本月分錄表（`.table-wrap`）；列印內容使用黑白或高對比樣式，文字清晰可辨；`.plates` 與 `.table` 加入 `page-break-inside: avoid`，避免分頁斷開關鍵資訊。
- **類別統計圖表**：帳本詳情頁在分錄表上方或下方嵌入 SVG 長條圖，顯示本月各類別支出總額與佔比；圖表中的金額皆經 `formatCents()` 格式化（整數分除以 100、千分位顯示），類別標籤使用繁體中文並經 `h()` 轉義；若本月無支出記錄，顯示「尚無支出紀錄」文字而非空白圖表。
- **錯誤處理**：SVG 圖表產生失敗時回退為 HTML 表格（類別＋金額＋佔比），金額同樣經 `formatCents()` 格式化、文字經 `h()` 轉義，不影響分錄表正常顯示；列印樣式不干擾一般螢幕檢視。

## Acceptance Criteria

1. 儀表板顯示各成員本月記帳筆數，且筆數與 entries 表中該帳本本月未刪除記錄一致。
2. 帳本詳情頁在本月支出 ≥80% 與 ≥100% 時分別顯示警告與超支提醒橫幅；未設定預算時不顯示預算區塊。
3. 使用瀏覽器列印帳本詳情頁時，側欄與操作按鈕被隱藏，僅保留合計牌與分錄表。
4. 帳本詳情頁顯示 SVG 類別統計圖表，標籤使用繁體中文；無支出紀錄時顯示文字提示。
5. 上述功能不破壞既有帳本權限檢查（僅授權使用者可查看對應帳本）與整數分金額儲存。

## Additional context

- **待確認**：成員記帳進度是否僅顯示「本月」，還需支援自訂月份？預算超支橫幅是否需在登入後彈出通知，或僅在頁面中顯示？列印月結單是否需包含簽名欄位供家長核對？
- **非本期範圍**：不新增多年度比較、多帳本彙總圖表、圖表匯出（PDF/Excel）或即時推播通知；既有 export_csv.php 已支援單一帳本匯出，本項不重複建置。
- **資料流**：
  - 成員記帳進度：儀表板 SQL 查詢 entries 表，加入 `WHERE e.ledger_id = :ledger_id AND e.deleted = 0 AND e.entry_date BETWEEN 本月首日 AND 本月末日`，GROUP BY user_id，join users 取得 username，輸出至儀表板 HTML 表格；針對每個可存取帳本分別查詢。
  - 預算超支提醒：複用 ledger.php 已有的 monthly_budget_cents 與 expenseCents 變數，僅在 `$isCurrentMonth` 為 true 且 `monthly_budget_cents > 0` 時計算，在 dashboard.php 與 ledger.php 顯示條件橫幅。
  - 列印月結單：ledger.php 在 `<head>` 內嵌 `@media print` CSS，隱藏 `.side`、`.nav`、`.ctr-actions`、`.quick`，保留 `.plates` 與 `.table-wrap`，加入 `page-break-inside: avoid`。
  - 類別統計圖表：ledger.php 在 PHP 端依 `entries.category` GROUP BY 計算各類別支出總額，金額經 `formatCents()` 格式化，產生 SVG `<rect>` 長條與 `<text>` 標籤，嵌入 HTML；失敗時回退為 HTML 表格。
- **身分驗證與權限**：所有查詢皆透過 ledger_access 做 IDOR 防護，使用者只能看到其被授權帳本的統計；類別圖表與成員進度皆在帳本授權範圍內。
- **資料傳輸加密**：無新增外部 API，SVG 與統計皆在伺服端渲染，直接輸出至 HTML，不額外傳輸。
- **非功能性需求**：SVG 圖表由 PHP 產生，不增加前端庫依賴，對行動網路載入影響極小；成員記帳進度單一 SQL 聚合查詢，效能影響可忽略；列印樣式僅在列印時生效，不影響一般頁面載入。
