# [#30] 修復現有功能，並以隔離資料驗證

> 本文件為規劃文件，不完全是實作依據。

## Description

修正全家人記帳系統已可重現的功能問題。測試環境可使用 Docker 或本機，正式部署仍沿用 cPanel、PHP 與 SQLite。

## User Story

家人能操作既有的記帳、對帳與管理功能，而不只是打得開頁面。

## To Reproduce

- 切換至台北時區，點選快速「今天」會因本地午夜轉 UTC 而倒退一日。
- 在原 CSP 下，重複記錄編輯、轉帳配對重置與多處操作確認沒有執行；既有頁面煙測不會偵測到。

## Expected behavior

快速日期遵從台北日曆；既有操作能依按鈕與確認提示完成；不放寬 CSP 或變更寫入權限，不恢復伺服器 PDF 下載。

## Acceptance Criteria

- [ ] 現有按鈕與確認在原 CSP 下運作。
- [ ] 快速日期在不同本地時區均以伺服器提供的日期為基準。
- [ ] 核心寫入、資料庫結果、既有列印、部署存取規則用隔離資料重新驗證；未驗證項目明列。

## Additional context

不部署、不改正式資料。既有需求仍以各任務文件為準；測試工具不納入正式執行階段依賴。
