# Planning: 快速記帳輔助（預設分類、快速日期、字級切換、語音回饋）

## Description

為「新增記錄」與「編輯記錄」頁面加入四項輔助功能，降低家庭成員（尤其是不熟科技的長輩）記帳門檻，使單筆記錄能在手機上更快完成：

1. **預設分類清單（Feature 2）**：類別欄位從純文字輸入改為「常用分類下拉選單＋自訂輸入」，避免一家人對同類支出使用不同用詞（如「餐費」、「吃飯」、「餐點」），導致統計無法歸類。
2. **快速日期按鈕（Feature 3）**：在記帳日期欄位旁加入「今天」「昨天」快速按鈕，點擊即填入對應日期，免除每次都從日曆選單選取。
3. **字級切換（大字模式）（Feature 4）**：全站加入字級切換開關，切換後介面字級遞增，適合視力較差的長輩閱讀。
4. **語音確認回饋（Feature 8）**：新增或編輯記錄儲存成功後，透過 Web Speech API 播報語音回饋（例如「支出 120 元已儲存」），讓長輩無需看螢幕即可確認操作成功。

範圍限於前述四項，不包含收據上傳、AI 解析、預算設定或後台管理等既有功能的擴充。

## User Story

- 作為家庭成員，我希望新增記錄時能從常用分類中選擇、快速選日期，以便在手機上 10 秒內完成一筆記帳。
- 作為長輩，我希望字級可以放大，且儲存後有語音回饋告訴我已記好，以便我不需仔細看螢幕也能確認操作成功。

## To Reproduce

本項目非錯誤（bug）類需求，不適用重現步驟。

## Expected behavior

- **預設分類清單**：新增／編輯記錄的類別欄位呈現下拉選單，預設包含「餐費、交通、娛樂、醫療、薪資、水電瓦斯、日用品、其他」；使用者可自行輸入不在清單中的自訂分類，後端限制 `category` 欄位長度上限 50 字元並經 `h()` 轉義輸出；所選或輸入的分類會正確儲存，並在帳本明細與統計中顯示。
- **快速日期按鈕**：記帳日期輸入框旁出現「今天」「昨天」按鈕；點擊後日期欄位立即填入對應的 Y-m-d 格式日期，表單可正常提交。
- **字級切換**：頁面出現字級切換開關；切換至大字模式後，全站標籤、輸入框、表格文字與按鈕字級遞增，偏好以 Cookie 保留（名稱 `font_size`，SameSite=Lax，過期 90 天，不設 HttpOnly，以便 JavaScript 讀取與寫入字級偏好；非敏感資訊，無需 HttpOnly），下次登入仍維持。
- **語音確認回饋**：記錄儲存成功並導回帳本詳情頁（ledger.php）後，後端於 session 設定 `voice_played=1` 並帶入語音內容（例如「支出 120 元已儲存」或「收入 5000 元已儲存」）；dashboard/ledger.php 檢查 session 標記，若 `voice_played=1` 則透過 Web Speech API 播放一次語音，隨即清除該標記，避免重複刷新重複播報；使用者可靜音或關閉瀏覽器標籤後語音不重複播放；若瀏覽器不支援 Web Speech API，則不顯示語音相關 UI，不影響正常記帳流程。
- **錯誤處理**：語音播放失敗不阻擋記錄儲存；字級切換失敗時維持預設字級；日期快速按鈕在行動裝置與桌面瀏覽器皆可正常點擊。

## Acceptance Criteria

1. 新增／編輯記錄表單的類別欄位包含預設分類下拉選單，並支援自訂輸入。
2. 記帳日期欄位旁具備「今天」「昨天」快速按鈕，點擊後日期欄位正確填入。
3. 全站具備字級切換開關，切換後字級遞增，且偏好以 Cookie 保留（名稱 `font_size`，SameSite=Lax，過期 90 天，不設 HttpOnly，以便 JavaScript 讀取與寫入字級偏好；非敏感資訊，無需 HttpOnly），下次登入仍維持。
4. 記錄儲存成功後，支援透過 Web Speech API 播報語音確認；瀏覽器不支援時不影響記帳流程。
5. 上述四項功能皆不破壞既有 CSRF 防護、權限檢查與整數分金額儲存機制。

## Additional context

- **待確認**：無（本期已決定：字級偏好以 Cookie 保留，名稱 `font_size`，SameSite=Lax，過期 90 天，不設 HttpOnly，以便 JavaScript 讀取與寫入字級偏好；非敏感資訊，無需 HttpOnly；語音回饋於 ledger.php 導回後透過 session `voice_played=1` 播放一次並清除標記）。
- **非本期範圍**：不新增自訂分類的後端管理頁面（自訂分類僅寫入 entries.category 欄位，不建立獨立分類資料表）；不新增語音輸入（僅語音輸出回饋，既有 AI 一句話記帳已含語音輸入，不重複建置）。
- **程式修改路徑**：新增／編輯記錄表單的類別欄位由 `<input type="text">` 改為 `<select>`（預設分類）＋自訂輸入，需在 `add_entry.php` 與 `edit_entry.php` 的表單 HTML 與後端驗證邏輯中調整，並保留既有 `csrf_token` 隱藏欄位；字級切換僅在前端透過 CSS class 切換，不涉及資料庫變更；語音回饋於 ledger.php 檢查 session 標記並播放。
- **資料流**：使用者在 add_entry.php / edit_entry.php 填寫表單 → 提交 POST → 後端驗證 CSRF 與權限 → 寫入 entries 表（整數分） → 導回 ledger.php → 前端依語音回饋設定播放語音；字級切換僅在前端透過 CSS class 切換，不涉及資料庫變更。
- **身分驗證與權限**：不變更既有登入與帳本權限模型，繼續使用 session 登入與 ledger_access 權限檢查（owner/member 可寫入，viewer 僅檢視）。
- **資料傳輸加密**：無新增外部 API 呼叫，語音回饋僅使用瀏覽器本機 Web Speech API，不傳輸語音資料至外部伺服器。
- **非功能性需求**：字級切換僅影響前端樣式，不影響頁面載入效能；語音回饋為瀏覽器本機 API，不耗用伺服器資源；預設分類為靜態清單，不增加資料庫查詢成本。
