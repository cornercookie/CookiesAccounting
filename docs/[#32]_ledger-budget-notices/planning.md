# [#32] 每月帳本預算提醒重複、百分比失真

> 本文件為規劃文件，不完全是實作依據。

## Description

延續 [#5] 全案驗收：帳本預算的摘要應正確反映當月支出，避免同一帳本出現兩個內容相同的完整提醒。既有 80%／100% 警戒邊界不變。

## User Story

作為查看儀表板或帳本的家庭成員，我需要看出實際使用率，並分清「剛到上限」與「已經超支」。

## To Reproduce

在隔離 PHP／SQLite 設每月預算 100 元，當月支出依序累計 79.99、80、100、150 元。儀表板低於 80% 無警示；到 80% 出現兩個完整提示；100 元時提示已超支；150 元時兩個提示仍寫 100%。另外在隔離帳本以 5,000 元預算和 7,500 元支出開啟帳本詳情，實測重複出現「本月預算已使用」提醒。

## Expected behavior

每頁每帳本最多一個完整的帳本層級警示。保留摘要列標籤和帳本詳情的預算進度；恰好到 100% 仍為紅色，但顯示已達上限，不說已超支。使用率顯示實值，僅進度條寬度最高 100%。

## Acceptance Criteria

- [ ] 帳本及儀表板於 79.99% 不顯示完整提醒、80% 黃色、100% 紅色且表示已達上限、150% 紅色且表示已超支。
- [ ] 每頁最多一個同帳本的完整提醒；150% 為文字顯示，帳本進度條仍最多 100%。
- [ ] 帳本的已花費及剩餘／超支金額保持正確；歷史月份與未設定預算時不出現完整提醒。

## Additional context

限 [#5] 帳本層級顯示；不變更類別預算、權限、儲存、資料表、路由或 cPanel 部署設定。
