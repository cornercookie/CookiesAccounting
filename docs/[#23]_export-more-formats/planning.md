## 功能描述

除既有逗號分隔值（CSV）與可攜式文件格式（PDF）匯出外，加入資料交換格式（JSON）匯出（方便資料遷移）與優化的逗號分隔值（CSV）匯出（含位元組順序標記（BOM）與中文欄位名，適合 Excel 開啟）。可選擇單筆傳票可攜式文件格式（PDF）列印。

## 專案函數與術語說明

- 輸出轉義函數（h()）：用於防護跨站腳本（XSS）。
- 跨站請求偽造（CSRF）：防護網頁請求被偽造的機制。
- PHP 資料物件（PDO）：用於資料庫查詢的預備陳述式介面，選用理由為符合專案「純 PHP + PDO 預備陳述式」技術約束，防止 SQL 注入。
- 預寫日誌（WAL）：SQLite 資料庫日誌模式，支援多讀與單寫併發（同一時間僅一個寫入者），選用理由為 SQLite 在多併發讀取場景下可避免鎖定失敗，符合共享主機環境需求。
- 帳本存取權限表（資料表識別名稱 ledger_access）：記錄使用者對各帳本的角色（擁有者（owner）/成員（member）/檢視者（viewer））。
- 登入檢查函數（requireLogin()）：檢查 $_SESSION['user_id'] 是否存在，未登入時導向 login.php，用於所有匯出入口的身分驗證前置檢查。
- 金額分轉元格式化函數（formatCents()）：將整數分儲存的金額轉換為元並保留兩位小數。
- 分類支出明細表（entries）：儲存所有記帳記錄的資料表，欄位包括記錄編號、帳本編號、使用者編號、金額（整數分）、類型、類別、記錄日期、備註、邏輯刪除標記（deleted）。
- 邏輯刪除標記（deleted）：entries 表欄位，業務意義為該筆記錄是否已作廢，0 表示未刪除，1 表示已作廢。
- JavaScript 物件標記法（JSON）：用於匯出結構化資料。
- 逗號分隔值（CSV）：用於匯出表格資料。
- 可攜式文件格式（PDF）：用於匯出列印檔案。
- 位元組順序標記（BOM）：用於標示 UTF-8 編碼。
- 8 位元組 Unicode 轉換格式（UTF-8）：字元編碼標準。
- 帳本識別碼（ledger_id）：用於識別使用者所屬帳本的編號，為資料庫 ledgers 表的主鍵。
- 匯出年月參數（ym）：指定匯出資料的年月，格式為 YYYY-MM（例如 2026-11），預設為本月。
- 單筆傳票編號參數（entry）：指定單筆記帳記錄的編號，為 entries 表的主鍵。
- 匯出格式參數（format）：指定匯出檔案格式，支援 json 與 csv 兩種值。
- 內容類型標頭（Content-Type）：HTTP 回應標頭，告知瀏覽器回應內容的媒體類型與編碼。
- 超文字傳輸協定（HTTP）：網頁請求與回應傳輸協定，用於瀏覽器與伺服端之間的資料傳輸。

## 使用者故事

作為家庭成員，我想將記帳資料匯出為 JSON 或 Excel 友善的 CSV，備份到個人電腦或交給會計處理。

## 預期行為

匯出功能支援 CSV、JSON 與 PDF 三種格式，使用者可選擇日期範圍（預設本月）進行資料匯出。

## 資料流（Data Flow）

使用者於匯出頁面選擇格式（CSV/JSON/PDF）與日期範圍 ym；伺服端驗證登入階段與 ledger_access 權限，依 ledger_id 與使用者角色（擁有者/成員/檢視者）確認帳本存取權限；以 PDO 預備陳述式查詢 entries 表，以 ledger_id 過濾該帳本記錄，並篩選邏輯刪除標記欄位（deleted）= 0（0 表示未刪除記錄）且符合日期區間的記錄；金額以金額分轉元格式化函數 formatCents() 轉換為元，保留兩位小數；所有欄位經 h() 轉義；以對應 Content-Type 輸出（application/json、text/csv 與 UTF-8 BOM、application/pdf）；上述為順利路徑，例外分支（權限失敗、資料庫失敗、參數錯誤等）詳見「錯誤處理與邊界條件」章節。

```mermaid
flowchart TD
    A[使用者選擇匯出格式與日期範圍] --> B[驗證登入與 ledger_access 權限]
    B --> C[依 ledger_id 確認帳本存取權限]
    C --> D[PDO 查詢 entries deleted=0 符合日期區間]
    D --> E[formatCents 轉換為元 h() 轉義]
    E --> F[以 Content-Type 輸出 JSON/CSV/PDF]
```

## 業務驗收條件

- export_csv.php 支援 ?format=json 分支，回傳 application/json，資料為該帳本所有未刪除記錄的陣列。
- CSV 匯出預設加入 UTF-8 BOM（\xEF\xBB\xBF）。
- CSV 欄位名稱使用中文，欄位順序：日期、類型、金額 (元)、分類、記錄者、備註。
- export_pdf.php 支援 ?entry=X 單筆傳票列印模式，輸出單頁 PDF，包含傳票編號、日期、類型、金額 (元)、分類、記錄者、備註欄位，所有文字經 h() 轉義。
- JSON 匯出設定 Content-Type: application/json; charset=utf-8。
- 金額匯出時以金額分轉元格式化函數 formatCents() 轉換為元，保留兩位小數。
- 除 PDF 二進位檔案外，所有文字輸出經輸出轉義函數（h()）轉義；PDF 文字層內容同樣經 h() 轉義。

## 錯誤處理與邊界條件

- 權限不足：requireLogin 未通過導向登入頁；ledger_access 無對應帳本則 HTTP 回應 403。
- 資料庫讀取失敗：顯示通用錯誤頁，詳細錯誤寫入 ./private_data/error.log。
- 匯出資料為空：回傳空陣列（JSON）或僅含標題行（CSV），非錯誤狀態。
- ym 參數格式錯誤：回退至本月，顯示提示訊息，HTTP 回應 400。
- 匯出失敗（檔案輸出失敗、JSON 編碼失敗）：顯示通用錯誤頁，HTTP 回應 500。
- format 參數值非 csv/json/pdf：回退至預設 CSV 格式，顯示提示訊息，HTTP 回應 400。

## 應用程式介面契約

- 匯出端點：export_csv.php（支援 ?format=json 與 ?format=csv 參數）、export_pdf.php（支援 ?entry=X 參數）
- 請求方法：GET
- 請求參數：format（json/csv，預設 csv）、entry（單筆傳票編號）、ym（年份月份，格式 YYYY-MM，預設本月）
- 回應欄位：JSON 格式為記錄陣列，每筆包含日期、類型、金額 (元)、分類、記錄者、備註；CSV 格式為含 BOM 的 UTF-8 編碼表格，欄位順序為日期、類型、金額 (元)、分類、記錄者、備註；PDF 格式為單筆傳票列印模式
- HTTP 狀態碼：200（匯出成功）、400（參數錯誤）、403（權限不足）、500（匯出失敗）
- 錯誤行為：參數錯誤時回應 400，權限不足時回應 403，匯出失敗時顯示通用錯誤頁並回應 500

## 身分驗證與權限控管

- 身分驗證：依賴既有 session 登入機制，requireLogin() 檢查 $_SESSION['user_id']，未登入導向 login.php。
- 權限控管：使用帳本存取權限表 ledger_access，角色分為擁有者（owner）、成員（member）、檢視者（viewer），三者皆可匯出。
- 資料傳輸加密：依賴既有 HTTPS Session Cookie 設定（secure、HttpOnly、SameSite=Lax）。
- CSRF 防護：匯出功能為僅讀 GET 請求，但為符合專案 CSRF 防護基線，仍需加入 CSRF 權杖防護，以 hash_equals() 驗證 csrf_token。

## 非本期範圍（Out of Scope）

- Excel (.xlsx) 格式：本期僅支援 CSV 與 JSON，不支援 .xlsx 二進位格式。
- 自動電子郵件匯出：本期不支援將匯出檔案自動發送電子郵件。
- 定時匯出：本期不支援排程定時匯出。

## 非功能性需求

- 預期效能：匯出頁面載入時間不超過 5 秒（大資料量時串流輸出避免記憶體過載）。
- 併發處理量：匯出為唯讀查詢，SQLite WAL 模式支援多併發讀取。
- 資料保留策略：匯出不產生額外資料，不涉及資料保留。
- 系統可用性：匯出失敗時顯示通用錯誤頁，不影響其他功能。
