## 功能描述

建立行事曆檢視頁面，以月曆格顯示每日收支總額，使用者可點入日期查看該日記錄。支援月份導航（上月/下月），純 PHP 伺服端渲染，無需前端行事曆庫。

## 專案函數與術語說明

- 超文字標記語言（HTML）輸出轉義函式（h()）：用於防護跨站腳本（XSS），所有使用者可控輸出皆經此函式。
- 登入保護機制（requireLogin()）：檢查 $_SESSION['user_id']，未登入導向登入頁。
- 帳本存取權限表（ledger_access）：記錄使用者對各帳本的角色（擁有者/成員（member）/檢視者）。
- PHP 資料物件（PDO）：用於資料庫查詢的預備陳述式介面。
- 超文字傳輸協定安全版（HTTPS）：用於資料傳輸加密。
- 月份參數（ym）：GET 查詢參數，格式 Y-m，用於指定行事曆顯示月份，驗證失敗時回退至當月。

## 使用者故事

作為家庭成員，我想以行事曆形式看到每天花了多少錢，快速找出特定日期的收支情況，適合手機橫向滑動月份。

## 預期行為

1. 預設顯示當月（Asia/Taipei 時區）行事曆。
2. 每日格顯示該日收入總額（紅色 +）、支出總額（藍色 -）、結餘。
3. 點入日期導向該日記錄清單（ledger.php 篩選或新增日視圖）。
4. 提供上月/下月導航按鈕，以年份月份參數 ym 傳遞月份。
5. 僅顯示使用者有帳本存取權限表（ledger_access）權限的帳本記錄。
6. 金額以整數分儲存，顯示時除以 100，千分位格式。
7. 所有輸出經 h() 轉義。
8. 表格使用 <table>，手機上可橫向滾動，觸控目標 ≥ 44px。
9. 無資料日期顯示空格或 0 元。
10. 可跨帳本加總（使用者所有可存取帳本）或單帳本檢視。

## 資料流（Data Flow）

使用者透過 GET 參數 ym 指定月份（格式 Y-m），伺服端以正則驗證 ym；以 PHP 資料物件（PDO）預備陳述式查詢 entries 表，篩選該月份內符合 帳本存取權限表（ledger_access）權限的記錄，依 entry_date 分組加總收入與支出；以 PHP DateTime 產生行事曆日期格；每日格顯示加總結果，所有輸出經 超文字標記語言（HTML）輸出轉義函式（h()）轉義。ym 參數驗證失敗時回退至當月，資料庫查詢失敗時顯示通用錯誤頁並記錄至 error.log。

## 業務驗收條件

- 行事曆頁面（calendar.php）可供使用者存取。
- 預設顯示當月（Asia/Taipei 時區）行事曆。
- 頁面以登入保護機制 requireLogin() 保護。
- SQL 查詢使用 PDO 預備陳述式，具名佔位符。
- 權限檢查：INNER JOIN 帳本存取權限表（ledger_access）與 la.user_id = :user_id。
- 月份導航以 GET 參數 ym 傳遞，格式 Y-m，經正則驗證。
- 每日收支加總查詢 entry_date = 當日日期，deleted = 0。
- 行事曆日期由 PHP DateTime 產生，不依賴 JavaScript 行事曆庫。
- 所有輸出經 超文字標記語言（HTML）輸出轉義函式（h()）轉義。
- 響應式表格，≤720px 可橫向捲動，觸控目標 ≥ 44px。

## 錯誤處理與邊界條件

- ym 參數格式錯誤（非 Y-m）：回退至當月，顯示提示訊息。
- 資料庫讀取失敗：顯示通用錯誤頁，詳細錯誤寫入 private_data/error.log。
- 無授權存取：requireLogin 未通過導向登入頁；ledger_access 無對應帳本則不顯示該帳本資料。
- 無資料日期：顯示空格或 0 元，非錯誤狀態。

## 身分驗證與權限控管

- 身分驗證：依賴既有 session 登入機制，requireLogin() 檢查 $_SESSION['user_id']，未登入導向 login.php。
- 權限控管：使用帳本存取權限表 ledger_access，角色分為擁有者（owner）、成員（member）、檢視者（viewer），僅顯示使用者有存取權限的帳本記錄。
- 資料傳輸加密：依賴既有 超文字傳輸協定安全版（HTTPS）Session Cookie 設定（secure 僅安全連線傳送、HttpOnly 僅伺服端可存取、SameSite=Lax 跨站請求限制）。
- 跨站請求偽造（CSRF）防護：行事曆頁面為僅讀 GET 導航，不涉及狀態變更操作，依專案安全約定不適用 CSRF 權杖；若未來加入狀態變更表單則需補充 CSRF 防護。

## 非本期範圍（Out of Scope）

- 多行事曆並行：本期僅支援單一月份檢視，不支援多個行事曆並排顯示。
- 農曆顯示：本期僅顯示公曆日期，不納入農曆。
- 行事曆匯出 iCal：本期不支援將行事曆匯出為 iCal 格式。

## 非功能性需求

- 預期效能：行事曆頁面載入時間不超過 3 秒（單月查詢）。
- 併發處理量：唯讀查詢，SQLite WAL 模式支援多併發讀取。
- 資料保留策略：行事曆檢視不產生額外資料，不涉及資料保留。
- 系統可用性：月份導航失敗時回退至當月，保證頁面可用。
