# Planning: 全家跨帳本總覽（儀表板加總）

## Description

在登入後儀表板（dashboard.php）新增「全家跨帳本總覽」區塊，將使用者可存取的所有帳本本月收支加總顯示，讓家庭成員一眼看到全家所有帳本的總收入、總支出與總結餘，不需要逐本點進去查看。

範圍限於儀表板新增加總區塊；不新增資料表、不擴充權限模型、不改變既有各帳本獨立查帳邏輯。

## User Story

- 作為家庭成員，我希望在儀表板一眼看到所有帳本本月的總收支，知道全家整體花了多少、剩多少。
- 作為管理員，我希望不需要逐個帳本進入，也能快速掌握全家各帳本本月收支狀態。

## To Reproduce

本項目非錯誤（bug）類需求，不適用重現步驟。

## Expected behavior

- **儀表板加總區塊**：在 dashboard.php 各帳本彙總表格（`<p class="summary-h">各帳本 · 本月收支</p>` 所在的 table-wrap）上方，新增「全家本月收支總覽」卡片，顯示：
  - 全家本月總收入（所有可存取帳本本月收入加總）
  - 全家本月總支出（所有可存取帳本本月支出加總）
  - 全家本月總結餘（總收入－總支出）
- **權限隔離**：加總僅針對目前登入者有存取權的帳本（透過 `ledger_access` 過濾），不會洩漏未授權帳本的資料。
- **月份一致**：加總使用與各帳本相同的本月（Asia/Taipei）範圍，不受查帳頁面月份切換影響（儀表板固定顯示本月）。
- **空白狀態**：若使用者目前沒有可存取帳本（`$ledgerSummaries` 為空），完全不顯示加總區塊，僅保留既有「目前沒有可存取的帳本」提示。
- **錯誤處理**：跨帳本加總邏輯以 `try/catch` 包裝；查詢失敗時呼叫 `logError()` 記錄至 `private_data/error.log`，並繼續顯示儀表板既有內容，不中斷頁面渲染。

## Acceptance Criteria

1. 儀表板顯示「全家本月收支總覽」區塊，包含總收入、總支出、總結餘三項數值。
2. 加總區塊位於各帳本彙總表格上方，與既有表格並存。
3. 加總範圍僅包含該使用者有 `ledger_access` 權限的未封存帳本（`archived = 0`）。
4. 金額格式與既有 `formatCents()` 一致（整數分除以 100、千分位顯示）。
5. 無可存取帳本時，完全不顯示加總區塊，僅顯示既有空白提示。
6. 與各帳本獨立彙總表格並存，不破壞既有帳本列表與詳情頁功能。

## Additional context

- **資料來源**：複用 `dashboard.php` 既有的 `$ledgerSummaries` 查詢結果（已透過 `INNER JOIN ledger_access ... AND la.user_id = :user_id` 過濾），在 PHP 端加總 `month_income`、`month_expense`，不新增 SQL 查詢。
- **時區**：本月判定以 `Asia/Taipei` 為準，與既有 `dashboard.php` 邏輯一致。
- **非本期範圍**：不新增跨帳本歷史報表、不新增多年度比較、不新增圖表匯出、不新增跨帳本預算。
- **效能**：每個帳本數十至數百筆記錄，PHP 端加總開銷可忽略不計。
- **錯誤處理實作**：`dashboard.php` 中加總邏輯用 `try { ... } catch (Throwable $e) { logError(...); }` 包裝，失敗時設定旗標 `$summaryError = true`，前端僅在無錯誤時顯示加總區塊。
